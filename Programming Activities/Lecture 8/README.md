# Lecture 8 - Microcontrollers and Circuits

This folder contains the programming activities, sensor data, and analysis completed for Lecture 8 of ENGR 095 - Sensing the World.

## Part 1 - Motors and Signals

* [servo_switch.py](servo_switch.py) - Uses a switch to control the position of a servo motor between 0° and 180°.

## Part 2 - Sensor Performance Data Collection

* [sensor_data_collection.py](sensor_data_collection.py) - Uses the Arduino Nano ESP32 ADC to read the analog output of a rain-drop sensor and record voltage measurements.
