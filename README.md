The repository documents my work with materials science, sensor fabrication, circuits, MicroPython programming, microcontrollers, data collection, and the development of our final automatic floodgate prototype.

## Final Project — Automatic Floodgate

The [Project](Project/) folder documents our final project: an **automatic floodgate prototype**.

The system uses a homemade **PEDOT:PSS humidity sensor** and a commercial **rain sensor** to detect unsafe moisture conditions. When either sensor detects moisture, a stepper motor automatically closes a sliding floodgate.

The system also includes:

- Red and green status LEDs
- A manual reset pushbutton
- A 28BYJ-48 stepper motor
- A ULN2003 motor driver
- A pulley/spool mechanism
- MicroPython control logic

The Project folder contains:

- Development and test programs
- Final MicroPython code
- Project photographs
- Final presentation slides
- A README describing the design process and how the system works
